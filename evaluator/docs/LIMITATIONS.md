# Limitations

In-memory data disappears on restart. No authentication, durable database, TLS, multi-host consistency, provider integration, real-world evaluation dataset or arbitrary-code sandbox. HTTP is loopback only; slow-client/socket resource limits are not measured. UI behavior is manually inspectable; its static check is not a browser E2E test. The separate React portfolio lab provides browser test evidence for that lab only.

The binary 100/0 score is contract compliance, not maintainability, safety or seniority. Abstention is not counted as success. These five synthetic cases cannot establish evaluator accuracy on an employer dataset. No independent reviewer has approved this new fixture. AI-assisted code and review artifacts are disclosed.
